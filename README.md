A one-page illustration of Saturday 21 November 2026 in world news: 35 dated stories,
7 colour-coded regions, three lead cards with original drawings, eight smaller cards and
a numbered index beside a real Natural Earth map. `entry.png` is 1024 x 1024 and ~204 KB.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies the committed `entry.png` into the output directory. `draw.py` rebuilds
the image from `STORIES` and `world110.geojson`; `verify.py` runs the local file and layout
checks.
